# AI Agents & Key/Cache Management

Shortify AI leverages a team of cooperative, specialized AI agents orchestrated to execute audio-visual parsing, creative design, rendering compilation, and caption checking.

---

## 1. Pipeline Agents

### 1.1 RhythmEngineer (`rhythm_service.py`)
- **Role**: Extracts musical properties from raw audio files to construct a temporal beat grid.
- **Technology**: `librosa` for audio processing.
- **Workflow**:
  1. Computes the envelope onset strength of the background audio track.
  2. Detects overall tempo (BPM) and absolute timestamps for beats.
  3. Calculates localized energy levels across frames.
  4. Identifies dynamic volume drops (useful for transition timing).
  5. Outputs a structured beat grid including tempo, beat times, sentiment, and music drops.
- **Optimizations**: Employs beat signature hashing (file size and timestamp) to cache analysis results, preventing redundant computation.

### 1.2 MediaAnalyst (`media_agent.py` & `media_service.py`)
- **Role**: Parses visual segments of raw user-uploaded videos to understand spatial layouts and semantic context.
- **Technology**: Google Gemini 1.5 Flash.
- **Workflow**:
  1. Uploads video assets to Google AI Studio.
  2. Prompts Gemini 1.5 Flash using structured instructions to analyze temporal regions.
  3. Extract key details for each segment: action descriptions, visual aesthetic quality score, primary subjects, face/speaking tracking, shot composition types (close-up, wide-shot), and brightness level.
  4. Returns structured analyses conforming to [media.py](file:///d:/ME/Shortify_BE/backend_ai/schemas/edl.py) schema formats.

### 1.3 CreativeDirector (`director_agent.py`)
- **Role**: Evaluates target constraints, music beat grids, and media semantics to design a cohesive, pacing-accurate edit plan.
- **Technology**: Groq / Llama 3.3 70B.
- **Workflow**:
  1. Combines the user brief, music beats, and segment visual analysis.
  2. Reasons over clip content to match fast beats with rapid visual motion and slow intervals with scenic/panning shots.
  3. Formulates a JSON Edit Decision List (EDL) containing segment selections, speeds, crop targets, transitions (none, crossfade, fade, slide_right, slide_up, slide_down, wipe, glitch), and text graphic overlays.
  4. Aligns timelines such that: `timeline_end - timeline_start = (end_in_clip - start_in_clip) / speed`.

### 1.4 VideoEditor (`editor_service.py`)
- **Role**: Reads the planned EDL structure, downloads visual overlays/stickers, and runs local rendering pipelines to compile clips.
- **Technology**: FFmpeg, OpenCV (`cv2`), `ffmpeg-python`, Giphy, and Pixabay APIs.
- **Workflow**: Performs early constant frame rate (CFR) resampling at 30 fps, stabilized pre-rendering, crop-scaling, speed adjustments (constant and speed-ramping curves), and audio-video stitching (see the [Rendering Pipeline document](file:///d:/ME/Shortify_BE/docs/rendering_pipeline.md) for depth).

### 1.5 SubtitleAgent (`subtitle_agent.py` & `subtitle_service.py`)
- **Role**: Performs speech-to-text conversion and validates text overlay safe zones.
- **Technology**: OpenAI Whisper (local, cpu/cuda) and FFmpeg filter graphs.
- **Workflow**:
  1. Transcribes speaking audio to generate word-level timestamps.
  2. Groups words into small subtitle chunks (configured in `caption_chunking.py`).
  3. Audits all text overlays generated by the Creative Director. If text falls into dangerous overlapping regions (top header, right actions bar, or bottom app metadata), it raises a safety warning and provides specific location adjustments back to the Creative Director for self-correction.
  4. Generates SRT subtitles and burns them onto the video stream.

## 2. Rotatable API Key Manager (`api_utils.py`)

To prevent API rate limit constraints (`429 Resource Exhausted`) and secure execution when uploading raw files to Gemini, the system utilizes a custom rotation layer:

```
                      +-----------------------------+
                      |     GeminiClientManager     |
                      +--------------+--------------+
                                     |
              +----------------------+----------------------+
              |                      |                      |
              v                      v                      v
      [ GEMINI_API_KEY ]    [ GEMINI_API_KEY_1 ]   [ GEMINI_API_KEY_2 ]
        Status: Pinned         Status: Cooldown        Status: Active
        Owner: file_abc        Time Rest: 12s          Hits: 2
```

### 2.1 File-to-Key Pinning (Ownership Lock)
When a file is uploaded to the Google API, the client manager registers which specific API key uploaded it inside `file_key_map`. Subsequent operations utilizing that file (such as querying model data or executing file deletion) are strictly locked to the exact same key. This prevents permissions exceptions (`403 PERMISSION_DENIED`) that would occur if key rotation happened mid-job.

### 2.2 Round-Robin Upload Load Balancing
File uploads are balanced in a round-robin loop across all configured key slots. This distributes media loading uniformly, protecting individual keys from hitting concurrent resource caps.

### 2.3 Key Cooldown Tracking
If a key triggers a 429 rate limit error, the client manager extracts the required backoff duration (using regex: `please retry in X seconds` or `retryDelay`), saves the cooldown timestamp, and bypasses this key slot entirely on subsequent operations.

## 3. Cache Directory Reorganization

To minimize processing costs, Shortify AI implements project-specific caching:

```
cache/
└── {user}/
    └── {project_id}/
        ├── clip_scores/
        │   └── clip_scores.json
        ├── media_analysis/
        │   └── media_analysis.json
        ├── music_analysis/
        │   └── music_analysis.json
        ├── director_analysis/
        │   └── director_analysis.json
        └── metadata/
            └── metadata.json
```

- **Cached Plan Fast-Track**: During pipeline initialization, the start node searches for `director_analysis.json` in the cache directory. If found, the system skips key-frame scoring, beat detection, media analysis, and timeline planning, loading the JSON plan and routing directly to video rendering.
- **TTL Expiration Disabled**: The 7-day age validation checks on Gemini media analysis files are disabled, keeping analysis outputs permanently cached to save costs.
- **Deletion Routing**: The `DELETE /projects/{project_id}/cache` endpoint allows developers to clear a project's cache folders recursively.
